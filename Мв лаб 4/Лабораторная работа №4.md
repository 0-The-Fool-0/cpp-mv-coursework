## Цель работы

Освоить составные квадратурные формулы с автоматическим выбором шага по правилу Рунге, сравнить численный и аналитический результат; научиться применять квадратуры Гаусса–Лагерра на полуоси для несобственных интегралов.

---

## Условия варианта 2

### Задание 1

Программа вычисляет с точностью \(\varepsilon = 10^{-6}\) интеграл

$$
\int_0^1 x\,e^{-x}\,dx
$$

с помощью **составной формулы Симпсона** и **составной формулы левых прямоугольников**.  
Для каждой КФ выводятся: приближённое значение, уточнённое по правилу Рунге значение, величина шага (при использовании сетки с числом отрезков \(n\): \(h = (b-a)/n\)). Результат сравнивается с аналитическим.

### Задание 2

С помощью частных случаев квадратурных формул наивысшей алгебраической степени точности (узлы — корни многочленов Лагерра) найти значение несобственного интеграла с точностью \(10^{-4}\).

В распечатке PDF формула во втором задании для варианта 2 восстанавливается неполно; в типовых методичках для этого места используется представление с весом \(e^{-x}\) на \([0, +\infty)\):

$$
\int_0^{+\infty} \frac{e^{-x}}{x+1}\,dx = \int_0^{+\infty} e^{-x}\,g(x)\,dx, \qquad g(x)=\frac{1}{x+1}.
$$

Именно этот интеграл считается ниже (КФ Гаусса–Лагерра). Если у вас в задании другая подынтегральная функция — достаточно заменить \(g(x)\) в программе и пересчитать «эталон» (аналитически или высокоточно).

---

## Теория (кратко)

**Составная формула Симпсона** на равномерной сетке с чётным числом отрезков \(n\), шаг \(h=(b-a)/n\):

$$
S_n = \frac{h}{3}\Bigl(f_0 + f_n + 4\sum_{i\ \mathrm{нечёт}} f_i + 2\sum_{i\ \mathrm{чёт},\ 0<i<n} f_i\Bigr).
$$

Порядок точности локальной формулы — \(O(h^4)\), в правиле Рунге для сравнения сеток «\(h\)» и «\(h/2\)» используется степень \(p=4\).

**Левые прямоугольники:**

$$
L_n = h \sum_{i=0}^{n-1} f(a + i h), \qquad p = 1.
$$

**Правило Рунге (оценка погрешности и экстраполяция):**  
если метод порядка \(p\), то

$$
\mathcal{R}_n \approx \frac{|I_n - I_{n/2}|}{2^p - 1}, \qquad
I^* = I_n + \frac{I_n - I_{n/2}}{2^p - 1},
$$

где \(I_n\) — значение на более плотной сетке (\(n\) отрезков), \(I_{n/2}\) — на сетке в два раза реже. Итерации продолжают дотех пор, пока \(\mathcal{R}_n \le \varepsilon\).

**Гаусс–Лагерр** (вес \(e^{-x}\), интервал \([0, +\infty)\)):

$$
\int_0^{+\infty} e^{-x} g(x)\,dx \approx \sum_{k=1}^{n} w_k\, g(x_k),
$$

где \(x_k\) — корни многочлена Лагерра степени \(n\), \(w_k\) — соответствующие веса. Число узлов \(n\) увеличивают, пока, например, \(|I_n - I_{n-1}| < 10^{-4}\) (или пока отклонение от аналитического значения достаточно мало).

**Аналитика для задания 1:** интегрирование по частям даёт

$$
\int_0^1 x e^{-x}\,dx = \bigl[-(x+1)e^{-x}\bigr]_0^1 = 1 - \frac{2}{e}.
$$

**Для задания 2:**

$$
\int_0^{+\infty} \frac{e^{-x}}{x+1}\,dx = e\,E_1(1),
$$

где \(E_1(x) = \int_1^{+\infty} \frac{e^{-xt}}{t}\,dt\) — интегральная показательная функция.

## Результаты вычислений

$$
I_{\mathrm{exact}} = 1 - \frac{2}{e} \approx 0{,}264\,241\,117\,657.
$$

|----|----------------------|---------------------|------------------------------|-------|-----------|--------------------------------|

Для гладкой функции формула Симпсона достигает \(\varepsilon = 10^{-6}\) при существенно меньшем \(n\), чем левые прямоугольники (первый порядок точности).

**Задание 2.**  
\(I_{\mathrm{exact}} = e\,E_1(1) \approx 0{,}596\,347\,362\).  
КФ Гаусса–Лагерра для \(g(x)=1/(x+1)\):

- при \(n = 8\): \(I_8 \approx 0{,}596\,215\), \(|I_8 - I_{\mathrm{exact}}| \approx 1{,}33\cdot 10^{-4}\) (чуть хуже заданной точности);
- при \(n = 9\): \(I_9 \approx 0{,}596\,279\), \(|I_9 - I_{\mathrm{exact}}| \approx 6{,}9\cdot 10^{-5}\);
- \(|I_9 - I_8| \approx 6{,}4\cdot 10^{-5} < 10^{-4}\).

Для отчёта с требуемой точностью достаточно взять **\(n = 9\)** (или больше).

## Особенности реализации

1. Симпсон требует **чётного** \(n\); сравнение «текущая сетка / в два раза грубее» начинают с \(n \ge 4\).
2. Для левых прямоугольников \(p = 1\), в формуле Рунге \(2^p - 1 = 1\).
3. Узлы и веса Лагерра можно брать из `numpy.polynomial.laguerre.laggauss` (как в `lab4_integrals.py`) или вычислять по стандартным таблицам/библиотекам.

## Код программы

'''
"""
Лабораторная работа №4 — вариант 2.
Задание 1: составные КФ Симпсона и левых прямоугольников, правило Рунге, ε = 1e-6.
Задание 2: КФ Гаусса–Лагерра для ∫₀^∞ e^{-x}/(x+1) dx, ε = 1e-4.
"""

from __future__ import annotations

import math
from typing import Callable, Tuple

import numpy as np


def f_task1(x: float) -> float:
    return x * math.exp(-x)


def exact_task1() -> float:
    """∫₀¹ x e^{-x} dx = 1 - 2/e."""
    return 1.0 - 2.0 / math.e


def composite_left_rectangles(f: Callable[[float], float], a: float, b: float, n: int) -> float:
    if n < 1:
        raise ValueError("n >= 1")
    h = (b - a) / n
    s = 0.0
    for i in range(n):
        s += f(a + i * h)
    return h * s


def composite_simpson(f: Callable[[float], float], a: float, b: float, n: int) -> float:
    """n — число отрезков, должно быть чётным."""
    if n < 2 or n % 2 == 1:
        raise ValueError("n must be even and >= 2")
    h = (b - a) / n
    s = f(a) + f(b)
    for i in range(1, n):
        x = a + i * h
        s += 4.0 * f(x) if i % 2 == 1 else 2.0 * f(x)
    return h / 3.0 * s


def runge_refine_simple(I_fine: float, I_coarse: float, p: int) -> float:
    """Роман-Рунге: I* = I_h + (I_h - I_{2h}) / (2^p - 1), I_h = более мелкий шаг."""
    # I_coarse = на сетке в 2 раза реже (больший шаг), I_fine = на сетке в 2 раза чаще
    return I_fine + (I_fine - I_coarse) / (2**p - 1)


def runge_error_estimate(I_fine: float, I_coarse: float, p: int) -> float:
    return abs(I_fine - I_coarse) / (2**p - 1)


def integrate_runge(
    method: str,
    f: Callable[[float], float],
    a: float,
    b: float,
    eps: float,
    n0: int = 2,
) -> Tuple[float, float, float, int]:
    """
    Автоматический выбор числа разбиений путём удвоения n до выполнения правила Рунге.
    Возвращает: приближённое I, уточнённое I*, оценку погрешности последней итерации, финальное n.
    """
    if method == "simpson":
        p = 4
        # Симпсон требует чётного числа отрезков; сравниваем сетки n и n/2 ⇒ стартуем с n ≥ 4
        n = max(n0 - (n0 % 2), 4)
        if n % 2 == 1:
            n += 1
        while True:
            I_coarse = composite_simpson(f, a, b, n // 2)
            I_fine = composite_simpson(f, a, b, n)
            err_est = runge_error_estimate(I_fine, I_coarse, p)
            I_star = runge_refine_simple(I_fine, I_coarse, p)
            if err_est <= eps:
                h = (b - a) / n
                return I_fine, I_star, err_est, n
            n *= 2
    elif method == "left_rect":
        p = 1
        n = max(n0, 1)
        while True:
            I_coarse = composite_left_rectangles(f, a, b, n // 2) if n >= 2 else float("inf")
            I_fine = composite_left_rectangles(f, a, b, n)
            if n < 2:
                n *= 2
                continue
            err_est = runge_error_estimate(I_fine, I_coarse, p)
            I_star = runge_refine_simple(I_fine, I_coarse, p)
            if err_est <= eps:
                h = (b - a) / n
                return I_fine, I_star, err_est, n
            n *= 2
    else:
        raise ValueError("method must be 'simpson' or 'left_rect'")


# --- Задание 2: Гаусс–Лагерр ---

def laguerre_gauss_nodes_weights(n: int) -> Tuple[np.ndarray, np.ndarray]:
    """Узлы x_i и веса w_i для ∫₀^∞ e^{-x} f(x) dx ≈ Σ w_i f(x_i)."""
    from numpy.polynomial.laguerre import laggauss

    x, w = laggauss(n)
    return x, w


def f_task2_multiplicative(x: float) -> float:
    """Подынтегральная функция g(x) в представлении ∫₀^∞ e^{-x} g(x) dx."""
    return 1.0 / (x + 1.0)


def exact_task2_multiplicative() -> float:
    """∫₀^∞ e^{-x}/(x+1) dx = e * E_1(1)."""
    try:
        from scipy.special import exp1

        return math.e * float(exp1(1.0))
    except ImportError:
        # без SciPy: приближение через asymptotic / не используем
        return 0.5963473613161933


def integrate_gauss_laguerre_tol(
    g: Callable[[float], float], eps: float, n_max: int = 200
) -> Tuple[float, int, float]:
    """Увеличиваем n до достижения оценки погрешности < eps (сравнение двух соседних n)."""
    prev = None
    for n in range(2, n_max + 1):
        x, w = laguerre_gauss_nodes_weights(n)
        val = float(np.sum(w * np.vectorize(g)(x)))
        if prev is not None:
            err_est = abs(val - prev)
            if err_est < eps:
                return val, n, err_est
        prev = val
    return prev, n_max, abs(val - prev)  # type: ignore


def main() -> None:
    eps1 = 1e-6
    eps2 = 1e-4
    a, b = 0.0, 1.0

    I_exact1 = exact_task1()
    print("=== Задание 1: ∫₀¹ x e^{-x} dx, ε = 10^{-6} ===")
    print(f"Точное значение (аналитически): {I_exact1:.12f}")
    print()

    for name, key in [("Симпсон", "simpson"), ("Левые прямоугольники", "left_rect")]:
        I_appr, I_star, err_est, n = integrate_runge(key, f_task1, a, b, eps1)
        h = (b - a) / n
        print(f"--- {name} ---")
        print(f"  Приближённое значение:     {I_appr:.12f}")
        print(f"  Уточнённое (Рунге):       {I_star:.12f}")
        print(f"  Оценка погрешности Рунге: {err_est:.3e}")
        print(f"  Число отрезков n:         {n}")
        print(f"  Шаг h:                    {h:.12e}")
        print(f"  |I - I_exact|:            {abs(I_appr - I_exact1):.3e}")
        print(f"  |I* - I_exact|:           {abs(I_star - I_exact1):.3e}")
        print()

    print("=== Задание 2: ∫₀^∞ e^{-x}/(x+1) dx ≈ Σ w_i g(x_i), g(x)=1/(x+1), ε = 10^{-4} ===")
    I_ex2 = exact_task2_multiplicative()
    val, n_used, err_est = integrate_gauss_laguerre_tol(f_task2_multiplicative, eps2)
    print(f"Точное значение (e·E₁(1)): {I_ex2:.12f}")
    print(f"КФ Гаусса–Лагерра (n узлов): {n_used}")
    print(f"Приближённое значение:       {val:.12f}")
    print(f"Оценка погрешности (|I_n-I_{{n-1}}|): {err_est:.3e}")
    print(f"|I - I_exact|:               {abs(val - I_ex2):.3e}")


if __name__ == "__main__":
    main()

'''

2. Формула Симпсона для \(f(x)=x e^{-x}\) на \([0,1]\) даёт нужную точность при малом \(n\); формула левых прямоугольников требует на несколько порядков больше узлов при том же \(\varepsilon\).
