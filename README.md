# MV C++ Coursework

A collection of independent C++ lab exercises. Each lab stays in its original directory with its own Visual Studio solution and project files where provided.

## Repository layout

- `Project1/` — an additional standalone Visual Studio project.
- `МВ Лаб 1/`, `МВ Лаб2/`, `МВ лаб 1 сем 4/`, `Мв лаб 3/`, and `Мв лаб 3_2/` — separate lab variants.
- `Мв лаб 4/` and `Мв лаб 5/` — later exercises with their own supporting materials.

The folder names are preserved from the original coursework; see each directory for its source code and any task-specific files.

## Build and run

Open the relevant `.sln` file in Visual Studio and build the selected assignment independently. Some assignments use local text files as input data. There is no single root executable or unified build command.

All six available Visual Studio projects built successfully with MSVC (v145 toolset override) in the Windows audit copy. Expected working directories and input-file paths still need runtime verification for each assignment.

## Scope and limitations

This is a coursework collection, not a maintained application. Build artefacts and local IDE state are excluded; source variants have not been merged. Confirm course rules and permissions before making it public.
