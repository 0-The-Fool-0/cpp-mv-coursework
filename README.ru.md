# Методы вычислений — лабораторные работы на C++

[English version](README.md)

Коллекция самостоятельных упражнений на C++ по вычислительным и численным методам. Каждая лабораторная находится в собственном каталоге вместе с проектом Visual Studio, если он был частью исходных материалов.

## Структура

- `Project1/` — дополнительный самостоятельный проект Visual Studio.
- `МВ Лаб 1/`, `МВ Лаб2/`, `МВ лаб 1 сем 4/`, `Мв лаб 3/`, `Мв лаб 3_2/` — отдельные лабораторные и варианты реализаций.
- `Мв лаб 4/` — материалы и отчёт по следующей лабораторной.
- `Мв лаб 5/` — материалы для заключительной работы.

Состав охватывает вычислительные задачи, работу с матрицами и численные эксперименты; названия сохранены из исходного учебного дерева, поскольку они нужны для сопоставления с заданиями.

## Сборка и запуск

Откройте `.sln` выбранной лабораторной в Visual Studio и запускайте её отдельно. Единого исполняемого файла и общей команды сборки нет. Для некоторых работ нужны текстовые входные данные в рабочем каталоге.

Сборка и тесты в рамках текущего обновления не запускались. Перед запуском проверяйте ожидаемую рабочую директорию и пути к входным файлам.

## Ограничения

Это архив учебных работ, а не поддерживаемое приложение. Сгенерированные артефакты и локальные настройки IDE не относятся к исходникам и должны оставаться вне Git.
